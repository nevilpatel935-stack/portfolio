# Nevil Patel — React Portfolio

A responsive personal portfolio built with React, Vite, Bootstrap 5 and custom CSS.

## Run locally

1. Install Node.js if it is not already installed.
2. Extract this ZIP and open the `nevil-portfolio` folder in VS Code.
3. Open the terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the localhost URL shown in the terminal.

## Customize

- Replace `public/profile.png` with your preferred profile photo (keep the same filename).
- `public/Nevil_Patel_CV.png` is the CV image supplied for this portfolio. The Download CV button downloads it.
- Update contact details in `src/components/Contact.jsx` if they change.
- Add verified GitHub/LinkedIn links when you are ready.

## Build for deployment

```bash
npm run build
```

The production site is generated in the `dist` folder.
